# Jobshadowapp

Create a unified web app for JobShadow (rebuilding and modernizing jobshadow.co.za and apply.jobshadow.co.za).

Key requirements:
1. Marketing & Public Experience:
   - Modern, welcoming homepage introducing JobShadow: facilitating job shadowing for high school students to explore careers before committing to tertiary education.
   - Job Roles catalog / browser: searchable, filterable career exploration library (Accounting, Law, Engineering, Tech, Healthcare, Creative, etc.) with role descriptions and required school subjects.
   - Clear value proposition for Scholars, Parents, Schools, and Host Companies/Mentors.
   - Contact & inquiry forms (Sponsor a learner, Host inquiry, School partnership).

2. Student / Scholar Registration & Application Workflow (rebuilding apply.jobshadow.co.za):
   - Multi-step guided registration workflow for high school scholars (one scholar per registration):
     - Step 1: Account setup & Scholar details (Full Name, Email, Phone, Grade / High School, City/Province in South Africa).
     - Step 2: Parent / Guardian details & consent (Name, Email, Emergency Contact).
     - Step 3: Career Shadow Selection (Choice of role / field, preferred format: in-person full-day shadow vs 1-hour digital interview, preferred dates/months).
     - Step 4: Motivation & Questions for the mentor.
     - Step 5: Review & Submit application.
   - Application status dashboard tracking application progress (Submitted -> Under Review -> Host Matched -> Date Confirmed -> Completed).

3. Design & Polish:
   - Professional, inspiring South African educational platform aesthetic with warm, trustworthy branding.
   - Clean navigation unifying the public marketing pages and the student application portal.
   - Responsive, polished UI with rich interactive states and mock data for immediate exploration.
